# CUS214 Employee Detail Check Report | Optimize this report with export Test Report

## Report Information

| Field | Value |
| --- | --- |
| Report Name | Employee Detail Check Report |
| Report Code | CUS214 |
| JIRA Issue | HERO-61720 |
| Component | REPORTS |
| Issue Type | Improvement |
| Report Design | Export program (replaces the previous report-engine output) |

## Parameters to Validate

| Parameters Name | Description | Options | Default |
| --- | --- | --- | --- |
| Shops/Outlets | Outlets whose employee detail checks are listed (multi-select) | All Outlets, Single Outlet, Multiple Outlets | All Outlets |
| Date Type | Date range type of the employee detail checks (single-select). Settings: Go to Platform: System Management > System Configuration > Report > Query Configuration: Maximum Query Days, Default: Empty, No Limit | Current Day, Last Day, Specified | Last Day |
| Begin Date / End Date | Date range boundaries, enabled when Date Type = 'Specified' | User Defined | - |

## Data Fields to Validate

| Fields Name | Fields Description | Field Calculation |
| --- | --- | --- |
| Report Header Date | Date shown in the report header; follows the hotel local calendar via the shop time offset (iTimeOffset) | localNow = BirtDateTime.addMinute(now, iTimeOffset - JVM offset); Last Day = addDay(localNow, -1) |
| Employee Detail Check Rows | Employee detail check rows from pos_check_extra_infos aggregated by business condition and joined to the main table via LEFT JOIN + pre-aggregation | Group and aggregate pos_check_extra_infos first, then JOIN once with the main table |

### 5.Regression Scope

- CUS214 all Date Types (Current Day / Last Day / Specified) on both UTC HQ and non-UTC HQ environments.
- CUS214 Auto Report mail attachments (Excel / PDF) generated by the export program.
