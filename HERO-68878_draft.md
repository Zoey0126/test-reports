# HERO-68878 Test Report

The Member module writes the warning Trying to access array offset on null to error.log at MemberApiGeneralComponent.php line 4477 when a duplicate profile merge is saved after the membership created for the test is deleted from the merge. The merge is saved successfully, but the membership data of the member is left in an inconsistent state. This bug fix removes the warning and keeps the membership data of the merged member consistent.

## Functional Testing

### 1. Duplicate Profile Merge With Membership Removal

#### 1.1. Merging Duplicate Profile After Deleting the Test Membership

**Prerequisite(s):**
1. The Member module is accessible and the user can log in with an administrator account.
2. At least two member profiles exist that can be selected in the Duplicate Profile page.
3. The Membership page is accessible and a "Test" membership can be created.
4. The error.log file is accessible, and its content is recorded before the test.

**Step(s):**
1. Go to the Membership page and create a "Test" membership.
2. Configure the "Test" membership for a member.
3. Go to the Duplicate Profile page and select the member and another member for merging.
4. Delete the "Test" membership in the merge.
5. Continue and save the merge.
6. Open error.log and check the entries from MemberApiGeneralComponent.php line 4477 generated at the merge time.

**Reproduction Result(s):**
1. The merge is saved successfully.
2. The membership data of the member shows an inconsistency after the merge.
3. error.log records the warning "Trying to access array offset on null" at MemberApiGeneralComponent.php line 4477.
4. No error message is shown on the Duplicate Profile page while the merge is saved.

**Fix Result(s):**
1. The merge is saved successfully.
2. The membership data of the merged member is displayed consistently after the merge.
3. error.log contains no "Trying to access array offset on null" entry at MemberApiGeneralComponent.php line 4477 after the merge.
4. No error message is shown on the Duplicate Profile page while the merge is saved.
