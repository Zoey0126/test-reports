## Report Data Accuracy Verification

### 1.Export File Format Option In Setup

#### 1.1.New Option Is Available With NDF Default
**Prerequisite(s):**
1. SUN POS Export Program configuration is accessible
2. Export File Setup section is available for sun_cover_account_v2_export

**Step(s):**
1. Open SUN POS Export Program configuration
2. Locate Export File Setup
3. Observe the new Export File Format option and its default value
4. Open the option list

**Test Result(s):**
1. A new Export File Format selection is available
2. The available options are NDF and TXT
3. NDF is selected by default

### 2.NDF Export Keeps Existing Behavior
**Prerequisite(s):**
1. Export File Format is NDF (default)
2. Known source data exists so the NDF output can be compared with the previous version

**Step(s):**
1. Keep Export File Format = NDF
2. Run SUN cover v2 export
3. Open the exported file
4. Compare format and content with the previous NDF-only behavior

**Test Result(s):**
1. The exported file is generated in NDF format
2. Existing export behavior remains unchanged
3. No other existing export logic or configuration is affected

### 3.TXT Export Generates TXT File
**Prerequisite(s):**
1. Export File Format can be changed to TXT
2. Known source data exists for Swire Hotels cover export

**Step(s):**
1. Set Export File Format = TXT
2. Save the export setup
3. Run SUN cover v2 export
4. Open the exported file

**Test Result(s):**
1. The exported file is generated in TXT format
2. The file can be used without a manual NDF-to-TXT conversion
3. Export content follows the existing SUN cover v2 logic

### 4.Switching Format Does Not Break Other Setup
**Prerequisite(s):**
1. An existing SUN cover v2 export configuration is in use

**Step(s):**
1. Change Export File Format from NDF to TXT and run export
2. Change Export File Format back to NDF and run export
3. Verify remaining Export File Setup fields are unchanged

**Test Result(s):**
1. Format can be switched independently
2. Other existing export configuration is not affected
3. Both NDF and TXT runs complete without error
