# HERO-69121 Test Report

The TMS module writes warnings to error.log while a reservation created by a member is edited and saved after the member is paused: Undefined array key "MemMember" at TmsApiReservationComponent.php line 9301, Undefined array key 0 at line 6989, and Trying to access array offset on null at lines 9301, 6992, 6829, 6828 and 6827. This bug fix removes these warnings from the TMS reservation workflow without changing the reservation result.

## Functional Testing

### 1. Error Log Warning Reproduction

#### 1.1. Reservation Save After Member Pause Logs Undefined Array Key "MemMember"

**Prerequisite(s):**
1. TMS Operation is available and the user can log in to the outlet under test.
2. A member exists with member information recorded on the member profile.
3. Member Management is accessible in a separate browser page or session.
4. The TMS error.log file is accessible, and its content is recorded before the test.

**Step(s):**
1. Go to TMS Operation > Search View page, search and make a reservation.
2. Edit the reservation record created by the member and record the member information shown.
3. Open a new page to pause the member.
4. Go to Member Management > Members page, search for the member and set the status to paused.
5. Return to the reservation editing page and modify the reserved "Special Remark" field.
6. Save the reservation.
7. Open error.log and check the entries from TmsApiReservationComponent.php generated at the save time.

**Reproduction Result(s):**
1. The reservation is saved.
2. error.log records the warning "Undefined array key "MemMember"" at TmsApiReservationComponent.php line 9301.
3. The warning is generated during the save of the reservation whose member is paused.
4. The same save operation also records "Trying to access array offset on null" at TmsApiReservationComponent.php line 9301.

**Fix Result(s):**
1. The reservation is saved successfully.
2. error.log contains no "Undefined array key "MemMember"" entry after the save.
3. No warning from TmsApiReservationComponent.php line 9301 is generated by the save operation.
4. The modified "Special Remark" value is stored on the reservation.
